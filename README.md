📌 Project Overview

This project uses Machine Learning classification algorithms to predict the credit risk category of applicants based on their financial and personal information.

The project preprocesses the dataset, trains multiple classification models, evaluates their performance, and predicts the credit category of a new applicant.

🎯 Objectives
Clean and preprocess credit-risk data
Handle missing numerical and categorical values
Convert categorical data into numerical form
Train multiple Machine Learning classification models
Compare model performance using different evaluation metrics
Visualize model performance using graphs and a confusion matrix
Predict the credit category of a new applicant
🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
🤖 Machine Learning Models

The following classification algorithms are used:

Logistic Regression
Decision Tree Classifier
Random Forest Classifier
